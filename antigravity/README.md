# 🛸 Antigravity Directory - Destino Vivo

Este directorio almacena los artefactos, componentes y definiciones JSON exportadas desde la plataforma Antigravity.

---

## 📁 Estructura

- `workflows/`: Exportaciones JSON de los flujos de trabajo (`daily-pricing-update.json`, `alert-detection.json`, `hotel-onboarding.json`).
- `pages/`: Definiciones visuales de pantallas de la aplicación.
- `components/`: UI Widgets reutilizables.
- `exports/`: Copias de seguridad completas del proyecto.
